# AuditManager

Plateforme de gestion des audits sociaux et environnementaux.

## Fonctionnalités

- 📋 Gestion des normes (ISO 14001, ISO 45001, SA8000...)
- 🏢 Gestion des entreprises et départements
- ✅ Checklistes d'audit configurables
- 📝 Réponses avec commentaires et pièces jointes
- ⚠️ Suivi des non-conformités
- 📅 Plans d'action correctifs
- 📊 Tableau de bord et statistiques
- 📄 Génération de rapports PDF

## Stack technique

- Frontend : React.js
- Backend : Spring Boot / Laravel
- Base de données : MySQL
